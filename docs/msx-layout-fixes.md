### Исправления интерфейса MSX

Категории открываются как список в оформлении VIO. Навигация не очищает фокус до получения следующей страницы; запросы NAS идут последовательно, SVG загружается перед заменой. Выбор категории выходит из режима избранного. Нумерация остаётся общей.

Оформление и координаты кнопок используют единый масштаб 16:9. Плеер VIO выводит видео с object-fit: contain на поверхности 16:9 в центре правой рамки. Встроенный плеер MSX в Windows не предоставляет этому интерфейсу API произвольного прямоугольника видео: для него предпросмотр отключён, OK запускает полный кадр на весь экран. При переходе VIO на встроенный плеер это ограничение сохраняется; обрезанный полноэкранный фон не используется. Работа мини-плеера VIO с потоками без CORS не гарантируется.

Изменения исходного кода не обновляют уже запущенный контейнер NAS: требуется deploy/update.sh. GitHub Pages требует отдельного включения в настройках репозитория.

Индикатор плеера VIO снимается по фактическому продвижению времени видео (timeupdate и контроль раз в 2 секунды), даже если после буферизации браузер не прислал повторное playing. Пауза очищает индикатор и не включает его от позднего waiting. Это исправление плагина VIO; поведение встроенного плеера MSX требует отдельной проверки на устройстве.
