# Проверка оформления VIO Direct

Область: приложение VIO, загружаемое с GitHub Pages внутри MSX. Проверяется общий тёмный фон, бирюзовый фокус, собственный SVG-экран и отсутствие переходов в системные панели в обычных сценариях приложения.

| Экран | Маршрут | Реализация |
|---|---|---|
| Каналы | home / all / move_* | Оформление VIO, глобальные номера |
| Категории | categories / categoryMove_* | Список VIO, количество каналов |
| Избранное | favorites | То же оформление; собственное пустое состояние |
| Настройки | settings | Полноэкранный интерфейс VIO |
| Звук и видео | audio | Интерфейс VIO; изменение громкости и отключение звука через API MSX без открытия его панели |
| Подключение | admin | Интерфейс VIO, видимый сохранённый ключ |
| Ввод ключа | key | Клавиатура VIO; ключ виден по умолчанию |
| Подтверждение удаления | confirmForget | Экран VIO с отменой |
| Нет ключа | connectRequired | Запрос подключения VIO вместо запуска пустого потока |
| Ошибка сохранения | storageError | Экран VIO с возвратом |
| Ошибка загрузки каталога | connectionErrorPage | Экран VIO с повторным подключением |

Кнопки «Настройки» и «Администратор» проверяются отдельно из каналов и категорий. В Direct они не должны открывать `panel:`, `info:` или системный `settings`.

Границы: настройки, меню, окно About и другие служебные экраны самого установленного Media Station X не принадлежат VIO. Нативные контролы/ошибки встроенного плеера и сообщения ОС этим обновлением не переоформлены. Нельзя считать заменённым интерфейс самого MSX. В варианте NAS старый отдельный клиент и серверная админка требуют самостоятельной проверки; этот аудит относится к GitHub Direct.

Автотесты проверяют все перечисленные маршруты, переходы из категорий, отсутствие системных панелей в сценариях VIO, ввод/удаление ключа и сохранение громкости. Визуальная проверка проводится в MSX web. Работа физических кнопок громкости и встроенного плеера дополнительно требует проверки на целевом устройстве.
