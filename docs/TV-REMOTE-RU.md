# ТЗ VIO. Управление телевизором с пульта

## Основной сценарий

Зритель выбирает категорию, находит канал по номеру и названию, смотрит эфир и одним нажатием возвращается к списку. Слева видна выделенная строка, справа — область просмотра. При открытии архива или настроек текущий канал остаётся известен приложению.

## Назначение кнопок

| Кнопка | Android TV | Media Station X |
| --- | --- | --- |
| ↑ ↓ в списке | Передвигать выделение | Передвигать выделение |
| OK | Выбрать канал, повторным нажатием развернуть. В эфире открыть список | Смотреть выбранный канал. В эфире открыть список через управление плеером |
| Назад | Закрыть окно, из полного экрана вернуться к списку | Вернуться к списку из плеера |
| CH+ / CH− | Следующий / предыдущий канал текущей подборки, с переходом через край | Следующий / предыдущий в подборке, если MSX передаёт команду плееру |
| VOL+ / VOL−, Mute | Управление громкостью телевизора или аудиосистемы | Управление громкостью устройства |
| Красная | Категории | Категории |
| Зелёная | Открыть избранное | Открыть избранное |
| Жёлтая | Архив включённого канала | Архив выбранного канала |
| Синяя | Медиатека iEdem | Настройки просмотра |

Цветные команды MSX действуют в списке каналов. На Android они также доступны в полноэкранном эфире. Диалоги и экранная клавиатура обрабатывают свои кнопки самостоятельно. Все разделы дублируются подписанными экранными кнопками. Для медиатеки через GitHub Pages требуется отдельно подтвердить совместимый HTTPS-доступ провайдера.

## Экраны и переходы

- Список сохраняет порядковые номера при фильтрации. Выделение различимо по фону и границе. Заголовок выбранного канала оставляет кнопку архива видимой.
- Верхнее меню Android прокручивается по горизонтали вслед за фокусом. Архив и медиатека доступны с главного экрана. Пустой архив до включения первого канала даёт подсказку.
- Архив в текущей версии предлагает время от одного часа до четырёх суток назад и возврат в эфир. Фактическая глубина зависит от канала. Следующая ступень — календарь EPG с названием передачи, временем начала и отметкой доступной записи.
- В медиатеке Android зритель проходит разделы, выбирает фильм и предложенное провайдером качество. Кнопка «Назад» из полного экрана возвращает в каталог. Настройка персонального портала находится под PIN.
- Потеря изображения, неподдерживаемый формат и недоступный архив должны иметь различимые сообщения, возврат к списку и повторную попытку. Переход на резервный плеер явно обозначает ограничения малого окна.

## Приёмка на телевизоре

1. С пульта без цветных кнопок открыть категории, выбрать канал, развернуть и вернуться. Отпускание OK должно оставить список открытым.
2. Листать вниз и вверх через границу экрана. Видно название и номер выделенного канала. При CH+ / CH− проверить первый, последний и единственный канал подборки.
3. Последовательно проверить цветные кнопки, включая пустое избранное. Удержание цветной кнопки открывает один раздел. Ввод PIN и редактирование полей работают как обычно.
4. Во время эфира, архива и фильма изменить громкость и отключить звук. Фокус и выбранный канал сохраняются.
5. Открыть архив жёлтой кнопкой, воспроизвести доступную запись, затем вернуться в прямой эфир. Проверить канал без записи.
6. На Android открыть медиатеку синей кнопкой и через меню. Запустить фильм, вернуться к разделам и затем на телевидение.
7. Повторить с крупным шрифтом, проверить видимость крайних пунктов и отсутствие обрезанного текста. Отдельно проверить Philips с физическим пультом и MSX с нативным плеером.

Сборка и программные тесты проверяют код и назначение действий. Аппаратные кнопки, вывод звука и декодирование реального потока принимает пользователь на телевизоре.
