# VIO

VIO — независимая русскоязычная универсальная медиаоболочка для [Media Station X](https://msx.benzac.de/). Проект предоставляет совместимые JSON-страницы MSX, HTTP API и расширяемую систему адаптеров источников.

> VIO не содержит медиаконтент, нелегальные каталоги, токены или секреты. Подключайте только собственные, открытые или лицензированные источники, которыми вы вправе пользоваться.

## Возможности

- стартовый объект `/msx/start.json`, меню и страницы для Media Station X;
- CORS для загрузки JSON со стороны MSX;
- API каталога и источников;
- реестр изолированных адаптеров;
- безопасный демонстрационный адаптер без внешних видеопотоков;
- TypeScript, тесты Vitest, Docker Compose и GitHub Actions.

## Быстрый старт

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

После запуска:

- `http://localhost:3000/health` — проверка сервиса;
- `http://localhost:3000/msx/start.json` — стартовый объект MSX;
- `http://localhost:3000/msx/menu.json` — главное меню;
- `http://localhost:3000/api/v1/sources` — список адаптеров;
- `http://localhost:3000/api/v1/catalog` — демонстрационный каталог.

Для стабильных абсолютных ссылок в MSX задайте публичный адрес:

```bash
PUBLIC_BASE_URL=https://vio.example npm start
```

Если переменная не задана, адрес определяется из текущего HTTP-запроса.

## Docker Compose

```bash
docker compose up --build
```

При необходимости создайте `.env`:

```dotenv
PUBLIC_BASE_URL=https://vio.example
```

## Подключение к Media Station X

1. Запустите VIO на сервере, доступном телевизору.
2. В Media Station X откройте **Settings → Start Parameter → Setup**.
3. Введите имя хоста и порт VIO. MSX запросит `/msx/start.json` автоматически.
4. Для HTTPS включите замок безопасности и укажите `PUBLIC_BASE_URL` с `https://`.

Все JSON-ссылки вне стартового объекта должны быть абсолютными. VIO формирует их автоматически.

## API

### `GET /api/v1/sources`

Возвращает описания зарегистрированных адаптеров.

### `GET /api/v1/catalog`

Параметры:

- `source` — идентификатор адаптера, по умолчанию `demo`;
- `search` — строка поиска;
- `limit` — от 1 до 100, по умолчанию 30.

### `GET /api/v1/catalog/:source/:id`

Возвращает одну карточку материала.

## Новый адаптер

Создайте класс, реализующий `SourceAdapter` из `src/adapters/source-adapter.ts`, затем зарегистрируйте экземпляр в `AdapterRegistry`. Адаптер должен:

- иметь уникальный `descriptor.id`;
- возвращать нормализованные `MediaItem`;
- не хранить ключи и пароли в репозитории;
- работать только с источниками, разрешёнными их владельцами и применимым законодательством.

Секреты передавайте только через переменные окружения на сервере. Не добавляйте их в `.env.example`, логи, тесты или MSX JSON.
