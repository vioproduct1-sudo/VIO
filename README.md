# VIO

VIO — независимая русскоязычная универсальная медиаоболочка для [Media Station X](https://msx.benzac.de/). Проект предоставляет совместимые JSON-страницы MSX, HTTP API и расширяемую систему адаптеров источников.

> VIO не содержит медиаконтент, нелегальные каталоги, токены или секреты. Подключайте только собственные, открытые или лицензированные источники, которыми вы вправе пользоваться.

## Возможности

- стартовый объект `/msx/start.json` и страницы для Media Station X;
- CORS для загрузки JSON со стороны MSX;
- API каталога и источников;
- реестр изолированных адаптеров;
- безопасный демонстрационный адаптер без внешних видеопотоков;
- компактный тёмный каталог с верхней навигацией и оригинальными постерами;
- разделы «Главная», «Фильмы», «Сериалы», «ТВ» и «Настройки»;
- запуск iEdem из вкладки «ТВ» с вводом личного ключа доступа в плеере;
- TypeScript, встроенный тестовый раннер Node.js, Docker Compose и GitHub Actions.

## Подключение прямо из GitHub — без своего сервера

В Media Station X откройте **Settings → Start Parameter → Setup** (Настройки → Стартовый параметр → Настройка) и введите:

```text
id:igd:vioiptv
```

Подтвердите установку VIO. При следующем открытии MSX интерфейс загрузится автоматически. Используйте актуальную версию Media Station X (с поддержкой ID-параметров).

Короткая ссылка [is.gd/vioiptv](https://is.gd/vioiptv) ведёт на [стартовый JSON в GitHub](https://raw.githubusercontent.com/vioproduct1-sudo/VIO/main/msx/start.json). Страницы берутся из ветки `main`; отдельный сервер Node.js для этой версии не нужен. Доступность зависит от GitHub и is.gd.

[Открыть VIO в веб-версии Media Station X](https://msx.benzac.de/?start=content%3Ahttps%3A%2F%2Fraw.githubusercontent.com%2Fvioproduct1-sudo%2FVIO%2Fmain%2Fmsx%2Fcontent%2Fhome.json&alias=VIO)

[Скачать исходники и JSON ZIP-архивом](https://github.com/vioproduct1-sudo/VIO/archive/refs/heads/main.zip). Готовый пакет **VIO-Media-Station-X** доступен в успешных запусках [MSX GitHub](https://github.com/vioproduct1-sudo/VIO/actions/workflows/msx.yml) → Artifacts (для скачивания артефактов требуется вход в GitHub). Для подключения на телевизоре скачивать ZIP не нужно.

**Границы этой версии:** опубликована существующая оболочка VIO, включая демонстрационные карточки и запуск внешнего ТВ-плеера. Самостоятельное IPTV с M3U/EPG, защищённая админка и Android APK этим изменением не реализованы. GitHub раздаёт только статические страницы: он не выполняет API и не хранит пользовательские настройки сервера. Личные плейлисты, ключи и пароли нельзя размещать в публичных JSON. Воспроизведение потоков и управление пультом требуют проверки на реальном телевизоре.

### Обновление опубликованных страниц

После изменения `src/msx/builders.ts` на Node.js 24 выполните:

```bash
node scripts/export-msx.mjs
node --test test/static-msx.test.mjs
```

Закоммитьте обновлённую папку `msx/` вместе с исходниками. Workflow `MSX GitHub` проверяет совпадение JSON с генератором, ссылки и собирает скачиваемый пакет. Для экспорта под другой адрес используйте `MSX_BASE_URL=https://example.org/VIO node scripts/export-msx.mjs target`.

## Быстрый старт

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

После запуска:

- `http://localhost:3000/health` — проверка сервиса;
- `http://localhost:3000/msx/start.json` — стартовый объект MSX;
- `http://localhost:3000/msx/content/home.json` — главная страница;
- `http://localhost:3000/api/v1/sources` — список адаптеров;
- `http://localhost:3000/api/v1/catalog` — демонстрационный каталог.

Для стабильных абсолютных ссылок в MSX задайте публичный адрес:

```bash
PUBLIC_BASE_URL=https://vio.example npm start
```

Если переменная не задана, адрес определяется из текущего HTTP-запроса.

## Docker Compose

```bash
docker compose up --build
```

При необходимости создайте `.env`:

```dotenv
PUBLIC_BASE_URL=https://vio.example
```

## Подключение к Media Station X

1. Запустите VIO на сервере, доступном телевизору.
2. В Media Station X откройте **Settings → Start Parameter → Setup**.
3. Введите имя хоста и порт VIO. MSX запросит `/msx/start.json` автоматически.
4. Для HTTPS включите замок безопасности и укажите `PUBLIC_BASE_URL` с `https://`.

Все JSON-ссылки вне стартового объекта должны быть абсолютными. VIO формирует их автоматически.

### iEdem по ключу доступа

Во вкладке **ТВ** выберите **iEdem TV**. Откроется совместимый ТВ-плеер, который принимает личный ключ доступа из кабинета iEdem. Плейлистную ссылку вводить не нужно. Ключ не передаётся серверу VIO, не записывается в логи и не хранится в репозитории. Используйте только собственную активную подписку.

## API

### `GET /api/v1/sources`

Возвращает описания зарегистрированных адаптеров.

### `GET /api/v1/catalog`

Параметры:

- `source` — идентификатор адаптера, по умолчанию `demo`;
- `search` — строка поиска;
- `limit` — от 1 до 100, по умолчанию 30.

### `GET /api/v1/catalog/:source/:id`

Возвращает одну карточку материала.

## Новый адаптер

Создайте класс, реализующий `SourceAdapter` из `src/adapters/source-adapter.ts`, затем зарегистрируйте экземпляр в `AdapterRegistry`. Адаптер должен:

- иметь уникальный `descriptor.id`;
- возвращать нормализованные `MediaItem`;
- не хранить ключи и пароли в репозитории;
- работать только с источниками, разрешёнными их владельцами и применимым законодательством.

Секреты передавайте только через переменные окружения на сервере. Не добавляйте их в `.env.example`, логи, тесты или MSX JSON.
