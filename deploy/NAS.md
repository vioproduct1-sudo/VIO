# Установка VIO на NAS

Целевой NAS: локальная сеть 192.168.8.222. Панель NAS /portal/ на порту 8001 и VIO — разные приложения. VIO использует порт **8088**.

## Через Docker / Portainer

1. Установите Docker Engine через App Central NAS (если он ещё не установлен).
2. В GitHub Actions откройте успешный запуск **VIO CI**, скачайте **VIO-NAS**, распакуйте ZIP и вложенный VIO-NAS.tar.gz в отдельную папку на NAS.
3. Скопируйте `.env.example` в `.env`. Задайте `VIO_ADMIN_PASSWORD` своим паролем от 8 символов. Это пароль VIO, не пароль NAS. Не загружайте `.env` в GitHub.
4. Из папки проекта выполните `docker compose up -d --build`. Для сборки NAS нужен доступ к Docker Hub и npm. Поддерживаются архитектуры, для которых доступен образ node:24-alpine; конкретная модель NAS не проверена.
5. Откройте **http://192.168.8.222:8088** на компьютере. Войдите через «Администратор», добавьте URL M3U/M3U8 или файл, затем EPG XMLTV.
6. В MSX используйте прежний `id:igd:vioiptv` и кнопку «Открыть телевидение». Альтернатива: стартовый параметр `192.168.8.222:8088`, который загрузит `/msx/start.json` с NAS.
7. В APK задайте `http://192.168.8.222:8088` в настройках сервера.

Секреты источников и хеш пароля находятся только в Docker volume `vio-data`. При обновлении не удаляйте volume. Переменная начального пароля используется только при создании базы; действующий пароль меняется в админке. После смены можно убрать начальный пароль из `.env`, но Compose требует непустое значение при проверке конфигурации.

При внешнем доступе настройте HTTPS reverse proxy на порт 8088, задайте `PUBLIC_URL` с HTTPS и `SECURE_COOKIES=true`. Не открывайте админку NAS в интернет ради VIO. Телеканалы предназначены для устройств в доверенной домашней сети: чтение `/api/channels` не требует пароля и включает URL потоков. Сам API не проксирует и не перекодирует медиапотоки.

HTTPS-версия MSX в браузере может блокировать переход/встраивание локального HTTP. Откройте VIO напрямую по HTTP в домашней сети либо настройте доверенный HTTPS на VIO. Не отключайте проверку сертификатов.

## Проверка

`http://192.168.8.222:8088/health` должен вернуть status=ok. После импорта проверьте канал, полноэкранный режим, Назад и избранное. Перезапустите контейнер: плейлист должен сохраниться.

**Фактическая установка на NAS не выполнена:** встроенный браузер отклонил сертификат панели. Нужен доступ пользователя к доверенной панели NAS, наличие Docker и запуск контейнера. В проекте не меняются настройки NAS, сертификаты и пароли NAS.
